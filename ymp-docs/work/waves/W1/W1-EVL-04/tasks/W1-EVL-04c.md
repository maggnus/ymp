## Outcome

A final report generated from frozen manifests and accepted evidence records one bounded decision
for instrumental reliability and one separate decision for collective-reasoning behavior, with
uncertainty, costs, failures, supported strata, and negative results preserved.

## Scope

### In

- Reproducible analysis artifacts, decision-rule evaluation, task-stratum results, effect and
  uncertainty estimates, audited false acceptance, infrastructure failure, cost, latency,
  abstention, communication interventions, limitations, and the next permitted product action.
- Explicit decisions to proceed narrowly, reject coordination as a reliability mechanism, reject
  the collective-reasoning claim, or invalidate the POC because the oracle or runtime failed.

### Out

- Retuning thresholds after results, suppressing null findings, claiming arbitrary-project
  reliability, authorizing MVP security by implication, or treating observed communication as
  consciousness.

- [ ] Regenerating the report from the frozen corpus, study manifest, run records, audit records,
  and analysis code produces the same primary estimates and decision.
- [ ] The reliability decision compares coordination with both required baselines at the

- [ ] The collective-reasoning decision cites controlled interventions and remains negative when
  communication appears fluent but lacks positive listening or task value.
- [ ] Oracle-integrity or comparison-compliance failure invalidates the POC instead of being
  omitted, relabelled, or averaged into candidate failure.
- [ ] Modifying a frozen primary input or applying a different post-hoc decision rule causes the
  reproducibility check to fail.
