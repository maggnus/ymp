Authority and medium. This section is the requirement contract for the later Rust implementation with Ratatui and Crossterm. It is not a web product specification. The HTML is a self-contained, offline review artifact: it defines terminal structure, projection fields, states, commands, and deterministic fixtures, but it does not add a browser client, service, listener, transport, protocol field, or kernel transition.

How to read the artifact. A row whose Source names a project document is REQUIRED; rows whose Source is Artifact composition, Existing …, or This contract are ARTIFACT choices and are also collected in the dedicated composition table below. An artifact choice must not be promoted into domain semantics. BLOCKING means W0-UX-01b or W0-UX-01c cannot accept the screen contract while the named trust, authority, verification, or terminal-outcome question remains unresolved. Existing values such as r-2419, p-02, costs, times, digests, paths, and message text are deterministic fixture values used to exercise templates; they create no requirement of their own.

Source path rule. Unqualified project-document names in the Source column resolve exactly under ymp-docs/. W0-UX-01a.md and W0-UX-01c.md resolve under ymp-docs/work/waves/W0/W0-UX-01/tasks/; ymp-rust/SCHEMA.md is already repository-relative. Section labels after § identify the exact source location.

Product boundary

  • Foreground local TUI in one installed ymp executable.
  • In-process typed application port; no operator socket, HTTP, WebSocket, daemon, or browser runtime.
  • POC claims experimental integrity in an externally disposable environment, not hostile-code containment.
  • POC-1 is the single-participant attempt; POC-2 adds local commitments, multiple participants, scoped collaboration, and the observatory.

Fixture rule

  • Every mockup declares data-template, data-projection, and data-fixture.
  • One template accepts zero, one, many, stale, degraded, failed, and terminal projection variants.
  • Fixture text never invents authority, ranking, causation, isolation, or preferred-candidate semantics.
  • The same projection fixtures feed Ratatui snapshots at 80×24, 120×40, and a wide high-volume size.

Phase legend

  • POC-1: foreground single-participant run.
  • POC-2: smallest self-organizing system and observatory.
