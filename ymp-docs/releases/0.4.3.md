# ymp 0.4.3

Installed locally on 2026-09-13.

This increment presents record collections as keyboard-navigable tables and includes the
interface corrections requested directly in Paseo. All record pages and the sidebar collections
use aligned columns. `/` filters rows, a leading `!` inverts the filter, and Shift plus a column's
underlined letter cycles ascending, descending and original order. Numbers sort numerically;
unknown values stay last. Column titles remain visible while scrolling. `d` opens Inspect, and
Enter retains the page's action. Memory search moves to `s`; `/memory QUERY` remains available.

Selection follows the same record through edits, live updates, sorting and filtering, including
pages that list one agent in several tables. Paste during filter editing stays in the filter.
Tables retain model-only scan names and invocation model/effort attribution. Historical rows
use their own recorded references, and an invalid reference never borrows a later invocation.
The conversation remains the main workspace.

The right sidebar contains session, tokens, team and tasks. Its navigation list is removed;
commands and the command palette open pages. Detailed mode expands stored agent messages,
including plans, reviews and execution reports. Slash completions and floating surfaces gain
consistent padding and aligned text, with margins that preserve the surrounding window rules.

The source changes are tracked in YMP-133, YMP-134 and YMP-135. This release changes presentation and
navigation; it requires no storage migration or provider authentication change.

YMP-135 also removes the placeholder suffix for unknown effort: the primary label shows only
the model until an actual effort is known. Binary thinking controls such as `on` and `off`
remain visible in details rather than standing in for a graded effort. Raw settings and
historical invocation links remain intact.
