# ymp 0.4.2

Agent selection now shows raw resolved model identifiers. Chat, active work and
assignment headings use the originating invocation's model and effort, shared
between the TUI and headless output. Native captions such as `Default (recommended)`
are source metadata rather than agent names. A factual native resolution replaces
the internal alias; historical messages are never relabeled from a later call.
The owner-requested `none` placeholder denotes an undefined effort in labels;
the stored requested, sent and reported values remain separate.

Claude's public SDK hooks supply applied main-turn effort when initialization
omits it, and expose tool activity. Child-agent settings do not overwrite the
parent's model/effort. This metadata observation adds no model prompt during scans.

This patch makes leaving the interface deliberate. A first `Ctrl+C` only shows
`Press Ctrl-C again to exit`. It no longer stops an active run or a catalog reading,
clears a draft or closes an overlay. A second press within two seconds leaves from any
region or overlay. Another key, a paste or the end of the window withdraws the request.
Repeat and release events are ignored when a terminal reports them.

Leaving by the second press, `/quit` or `Ctrl+D` first paints what is being stopped. ymp
then cancels the run and the catalog reading, waits up to 10 seconds for them to record
their state, restores the terminal and prints `Resume this session with:` followed by a
shell-quoted command. The command names the absolute metadata directory with `--home`,
the session's saved project directory and its ID, so it does not depend on `HOME` or
`YMP_HOME` in the shell that runs it. A session that a run opened while ymp was closing
is included. It opens the conversation without starting agents; `/resume`
continues the run. A window without a session prints no command. `/stop` and `/pause`
still stop a run without leaving. No storage migration or provider change is required.

ymp does not ask the terminal to report key event types. A terminal that delivers a held
`Ctrl+C` as repeated, indistinguishable presses therefore leaves ymp while the key is held.
Work that has not stopped after 10 seconds is left behind, and ymp says so before the
resume command.

(two existing fixture tests remain ignored), and all 18 Claude bridge tests.

labels, decoded-answer attribution, SDK-hook effort and tool-event forwarding.

exit, input/timeout reset, /quit, sessionless exit and shell parsing of the saved
session command. A scripted ACP process verifies first-press non-cancellation,
second-press cancellation, paused session state and revoked authority. Another
scripted ACP workflow verifies model/effort headers for shared chat and native
responses through the actual CLI. No real provider inference is used as a test.
