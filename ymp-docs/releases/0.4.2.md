# ymp 0.4.2

This patch makes leaving the interface deliberate. A first `Ctrl+C` only shows
`Press Ctrl-C again to exit`. It no longer stops an active run or a catalog reading,
clears a draft or closes an overlay. A second press within two seconds leaves from any
region or overlay. Another key, a paste or the end of the window withdraws the request,
and repeated or released key events are not a second press.

Leaving by the second press, `/quit` or `Ctrl+D` first paints what is being stopped. ymp
then cancels the run and the catalog reading, waits up to 10 seconds for them to record
their state, restores the terminal and prints `Resume this session with:` followed by a
shell-quoted command. The command names the session's saved project directory, its ID
and `--home` when metadata is not in `~/.ymp2`, including a session that a run opened
while ymp was closing. It opens the conversation without starting agents; `/resume`
continues the run. A window without a session prints no command. `/stop` and `/pause`
still stop a run without leaving. No storage migration or provider change is required.

Terminals that do not report key event kinds deliver auto-repeat as ordinary presses, so
holding `Ctrl+C` there can count as the second press. Work that has not stopped after 10
seconds is left behind, and ymp says so before the resume command.

## Validation

Three keyboard tests failed against the 0.4.1 source: the first `Ctrl+C` returned
`Cancel` during a run and `Quit` when idle, and two presses in the command palette did
nothing. After the correction formatting, strict workspace Clippy and all 441 workspace
tests pass, 155 of them interface tests; two existing fixture tests remain ignored. The
new tests cover the two-second window, withdrawal by input and by expiry, repeats and releases, every focus
region and an overlay, `/quit` and `Ctrl+D`, the bounded wait, a session reported while
stopping, and resume commands read back through `sh`, `bash` and `zsh` with quotes,
spaces and control characters.

A debug build was driven in a pseudo-terminal with deterministic local agents. The first
`Ctrl+C` painted the request without exiting; the second exited with status 0 in about
20 ms, after the alternate screen was left, and printed the saved project directory,
custom home and session ID. No model was asked anything. The release build and installed
verification belong to integration.
