# ymp 0.4.4

Installed locally on 2026-09-13 from source `dc97d0ea0e3de55c59eb5fe514b09ee99c868cfb`.

`/files` now uses ratatui-explorer 0.3.0 to navigate directories, retain selection on return,
filter names and open source previews. Browsing may ascend above the starting directory without
changing the execution directory. Failed directory entry leaves the previous list intact. Names
are escaped for display while original paths identify files. The page uses the component's
native directory/name ordering; other record pages keep table sorting.

File previews and message Inspect use tui-syntax-highlight 0.2.0, syntect 5.3.0 and two-face
0.5.2 grammars. Content reads are bounded to 256 KiB. Binary, unsupported-encoding, missing and
special files receive explanatory messages. Highlighting has line-length and time limits and
uses the current semantic theme. Inline conversation highlighting follows in YMP-140.

Ratatui is updated to 0.30.2. Ember and Slate remain available alongside sixteen palettes from
ratatui-themes 0.3.0. All eighteen themes are reachable in short terminal windows. The source
changes are tracked in YMP-136, YMP-137 and YMP-139; no storage migration is required.
