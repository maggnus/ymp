# General trial skill validation

The repository skill `ymp-trials` and shared protocol cover tests, integration,
native trials and product research independently of the fifteen-puzzle case.
The accepted intent has not changed. One template carries criteria from plan
through observations, causal analysis and acceptance.

## Independent application

Claude Opus 5 xhigh applied the skill to a synthetic source-grounded document
retrieval-policy question, with only read-only appraisal authorized. The exact
[result and reviewed source hashes](opus-forward-use.md) are retained here. The
numbers in that scenario are supplied hypothetical evidence, not new product
measurements. No tests, native runs, publication or repository writes were made
by that evaluation.

The application did not impose game controls, a browser or publication. It kept
the proposed policy benefit unestablished despite twelve unrelated passing tests
and one completed/unconfirmed document session. It proposed scoped evidence
appraisal and separated future execution from current authority.

## Corrections from the application

| Finding | Correction |
| --- | --- |
| F1: obsolete three-mode list in the study card | The card references the canonical mode table and records authorized phase separately. |
| F2: planning/retrospective appraisal and evidence suitability implicit | Explicit phase selection and general existing-evidence appraisal now precede execution and interpretation. |
| F3: conditional criteria undefined | The predeclared trigger makes the criterion required; absent evidence is unknown, not an absent trigger. |
| F4: register writes unconditional | Register updates occur within authorized scope; read-only/ad-hoc work can return a proposed status note. |

The synthetic request specifically excluded execution. This is not a universal
rule to request new permission for ordinary authorized local diagnostics. The
protocol makes that distinction explicit.

## Validation and limits

Skill Creator `quick_validate.py` and local-reference checks verify syntax and
structure. The bounded independent application above supplies behavioral evidence
of non-game adaptation; the parent reviewed the four resulting text corrections.
No second native experiment or large test matrix was needed.

This does not demonstrate better runtime outcomes, model quality or causal gains
from the skill. Repeated use may reveal additional improvements. The still-pending
native repetition is a separate application, not a prerequisite for availability
of this reusable project skill.
