|---|---|---:|---|---|

## Продуктовая матрица

Обозначения: ✅ работает и подтверждено; 🟡 работает частично или только как техническая основа;
⛔ отсутствует либо закрыто безопасным отказом; 📐 принят дизайн, но нет реализации.

| Область продукта | Статус | Работает сейчас | Не работает / разрыв | Следующий доказуемый шаг |
|---|---:|---|---|---|
| Один устанавливаемый продукт | ✅ | Один Rust executable `ymp`; foreground Ratatui; частные child modes | Обычная машина не считается безопасной песочницей для враждебного кода | Сохранять одноисполняемую границу при новом UX |
| Журнал, объекты и восстановление | ✅ | Digest-linked journal, атомарные метаданные, CAS-объекты, восстановление, честные терминалы | Полный production backup/migration/restore относится к более позднему этапу | Не ослаблять при изменении интерфейса |
| Кандидат и проверка | ✅ | Изолированная попытка, immutable candidate, exact verifier evidence, отрицательные контроли, экспорт | Сила проверки зависит от задачи; впечатление пользователя не доказательство | Разделять «проверено» и «оценено человеком» |
| Codex и Claude Code runtime | ✅ | Managed launch, events, usage, resume, cancel, bounded shutdown | Конкретная среда может оказаться несовместимой; macOS POC best-effort | Проверять доступный runtime перед реальным run |
| Поставщики и каталог моделей | 🟡 | Enable/disable, disclosure consent, background catalog, честная ошибка | Managed sign-in и единая привязка поздних ошибок не завершены | Замкнуть setup/error path |
| AgentPool | 🟡 | Допустимые entries, automatic `default`, frozen snapshot | Ceilings не проведены через все start/recruitment/spend paths | Провести пределы через исполнение |
| Goal → result | 🟡 | Typed prompt создаёт внутренний contract и run; один участник выдаёт кандидат | `/authorize`, внутренние ID и английский check derivation противоречат User Journey | Русская нормализация, затем убрать церемонию |
| Коллектив и recruitment | 🟡 | Origin participant и recruitment gate существуют | Сквозной product run нескольких участников не доказан | Свежий multi-participant e2e |
| Общая доска | 🟡 | Agent publish/read, inert payload, scope/audience, operator projection | Нет target TUI read и human write | `/board`, затем user intervention path |
| Цитирование и пересмотр | 📐 | Семантика принята в Protocol и User Journey | Целевой observatory не реализован | Показывать отдельные факты без causal claim |
| Прозрачность команды | 📐 | Принят договор видимой фактической команды | Текущий TUI его не реализует | Новый дизайн и Application projections |
| Результат и ручная оценка | 📐 | Принят внешний run/open и отдельные доказательства | Полный flow не реализован; TUI не должен встраивать приложение | External launch → feedback → explicit apply |
| Изменение результата | 🟡 | Candidate ancestry сохраняет версии | One store/one run; conversational revision ограничен | Новый run/version с provenance |
| Текущий TUI | 🟡 | Технически работает и тестируется | Информационная архитектура отклонена как системоцентричная | Проектировать из User Journey + Design Context |
| Live model admission | ⛔ | Zero-model gates, compatibility, probe transport и диагностика реализованы | Process-cleanup conformance не доказана; attestation отсутствует; `model_ready=false` | Новый owner-gated preflight/live node |
| Matched-budget эксперимент | ⛔ | Protocol, corpus и decision rules готовы | Arms не выполнены | Открыть gate и провести frozen study |
| Причинная проверка сообщений | ⛔ | Interventions и запрещённые ложные метрики определены | Experimental arms не выполнялись | После transfer gate и instrumental result |

## Блокировки

| Блокировка | Следствие | Что открывает |
|---|---|---|
| Новый дизайн ещё не создан и не выбран | TUI implementation остаётся deferred | Результат Claude Design и решение владельца |
| Русская нормализация и сильная проверка отсутствуют | «Морской бой» остаётся DESIGN-эталоном | Backend slice с различающей проверкой |
| Process-cleanup preflight не доказан | Model gate закрыт | Новый owner-gated diagnostic node |
| Нет controller attestation | Weak participant experiment запрещён | Принятый live admission result |
| Нет matched-budget данных | Нельзя утверждать reliability/self-organization | Завершённые POC-3 arms |
